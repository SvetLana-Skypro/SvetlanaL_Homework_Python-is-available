ОТЧЁТ О ДЕФЕКТАХ (BUG REPORT) — КЛАСС STRINGUTILS
====================================================================

Дефект №1: Изменение регистра последующих заглавных букв в методе capitalize()
--------------------------------------------------------------------
- Шаги для воспроизведения:
  1. Вызвать метод utils.capitalize("skyPro")
- Фактический результат: Метод возвращает "Skypro" (буква 'P' стала строчной).
- Ожидаемый результат: Метод должен делать заглавной ТОЛЬКО первую букву. Ожидалось: "SkyPro".
- Критичность: Medium (Нарушает логику обработки строк со сложным регистром).

Дефект №2: Ошибочное нахождение пустой строки в методе contains()
--------------------------------------------------------------------
- Шаги для воспроизведения:
  1. Вызвать метод utils.contains("SkyPro", "")
- Фактический результат: Метод возвращает True.
- Ожидаемый результат: Метод должен возвращать False, так как пустой символ не является частью искомого текста.
- Критичность: Low (Логическая помарка при работе с пустыми граничными значениями).

Дефект №3: Критическое падение методов при передаче значения None
--------------------------------------------------------------------
- Шаги для воспроизведения:
  1. Вызвать любой метод, например utils.capitalize(None)
- Фактический результат: Программа аварийно завершается с ошибкой AttributeError: 'NoneType' object has no attribute 'capitalize'.
- Ожидаемый результат: Метод должен корректно обрабатывать входные данные (например, возвращать сообщение об ошибке или обрабатывать исключение), не вызывая падения всей утилиты.
- Критичность: High (Блокирует работу программы при незаполненных данных).
